Midnight Vault is a 2D top-down heist game for desktop browsers. Play Wren, a thief crossing three vault rooms: read sweeping guard vision cones and camera sweeps, spend EMP / smoke / noise tools (each raises the alarm meter), grab the glowing prize and reach the getaway door.

## Run it

```sh
node serve.ts --port 8080   # then open http://localhost:8080
```

## Controls
WASD/arrows move · Shift crouch · 1/2/3 tools · mouse aim + click throw · R retry · M mute
